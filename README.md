# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 归档区：仅贴线进度 100%、交付日期已到且无未处理缺陷的作品可归档，不满足时提示具体原因；归档时记录归档时间，并冻结胎体、纹样、金粉、缺陷与流转记录。
- 归档作品从看板与风险列表移出，在归档区按交付日期倒序查看；可恢复为待交付，原有流转记录保留并接续。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。
- 旧版本地数据首次打开时自动补上未归档状态，不丢数据。

文件结构：
- `index.html`：页面结构
- `styles.css`：全部样式
- `storage.js`：localStorage 读写、种子数据与旧数据迁移
- `render.js`：风险列表、看板、归档区与详情弹窗渲染
- `app.js`：作品状态、工序流转、归档/恢复与事件绑定
