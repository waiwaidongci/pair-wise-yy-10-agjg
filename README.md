# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 归档区：仅进度 100%、交付日期已到且无未处理缺陷的作品可归档，不满足时提示具体原因；归档时记录归档时间，并冻结胎体、纹样、金粉、缺陷和流转记录。
- 归档作品从看板和风险列表移出，在归档列表按交付日期倒序查看；可恢复为待交付，原有流转记录保留。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。
- 旧 localStorage 数据首次打开自动补上未归档状态，数据不丢失。

文件结构：
- `index.html`：页面结构
- `styles.css`：全部样式
- `storage.js`：localStorage 读写与旧数据迁移
- `render.js`：看板、风险列表、归档区渲染
- `app.js`：状态、操作（含归档/恢复）与事件绑定
